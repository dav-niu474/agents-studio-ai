# 场景词模板 · 国风二次元

---

## 模式 A · 中文

```
[画风 prefix.md]，
{location}，{time_of_day}，{lighting}，{ambience}，
{era 时代背景，如有},
{scene.prompt_en 翻译为中文的具体描述},

无人物，纯背景，电影感构图，
[质量锁定词]
```

### 国风专属约束词

按场景类型加（与 director_storyboard.md 同步）：

| 场景类型 | 必加约束 |
|---|---|
| 仙侠 | 云雾缭绕、飞檐亭台、青绿山水、赛璐璐平涂 |
| 宫廷 | 朱红宫墙、金顶琉璃、雕梁画栋、汉白玉栏杆 |
| 闺阁 | 屏风格扇、雕花窗棂、纱幔帐帘、古典家具 |
| 武侠 | 竹林/雪地/山崖、冷色调、氛围压抑、线条凌厉 |
| 节日 | 灯笼/彩带/烟花、高饱和暖色、氛围热闹 |
| 夜街 | 灯笼/街灯、暖光点缀、冷色背景、倒影反射 |

## 模式 B · 英文

```
[prefix.md mode B],
{location}, {time_of_day}, {lighting}, {ambience},
{era},
{scene.prompt_en},

No characters, pure background, cinematic composition,
[quality_lock_en]
```

### Negative (mode B)

```
photorealistic, realistic photography, 3D render,
modern buildings, contemporary objects (unless story setting requires),
characters, people, pedestrians, blurry, low quality,
no text, no watermark
```

## 时间段光线对照

| 时间段 | 主光 | 色调 | 氛围 |
|---|---|---|---|
| 清晨 | 柔和晨光，暖色侧射 | 月白 + 青绿 | 薄雾弥漫，空气清新 |
| 正午 | 明亮阳光，直射柔光 | 朱红 + 金黄高光 | 光影清晰，色彩鲜明 |
| 黄昏 | 逆光剪影，暖色渐变 | 朱红 + 靛蓝渐变 | 夕阳余晖，轮廓光 |
| 夜间 | 冷色背景 + 暖光点缀 | 靛蓝主调 + 暖黄光点 | 宁静温馨，灯光柔和 |
| 雨天 | 漫射冷光，无主光源 | 青绿 + 月白 | 空气湿润，低对比 |
