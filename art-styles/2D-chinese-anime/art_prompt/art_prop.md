## 国风道具风格约束

| 类型 | 风格词 |

| 武器 | 古典纹饰、铜锈感、东方刀剑形制 |
| 法器 | 玉质、流光、青烟缭绕、符文 |
| 日用 | 木质、竹质、瓷器、漆器 |

| 文房四宝 | 墨色、竹简、宣纸、青砚 |
| 食物 | 古风食器、蒸汽、暖色调 |
